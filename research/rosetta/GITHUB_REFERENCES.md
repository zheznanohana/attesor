## Concrete decision changes

1. Probe `/Library/Apple/usr/lib/libRosettaAot.dylib`, not only runtime and
   libRosettaRuntime. `aotinvoke` provides a more direct observation path than
   the previous unsuccessful LLDB guest launch. Its feasibility on our runner
   remains a test result, not an assumption.
2. Use the actual exported mangling to reconstruct by-value `Interval` and
   `std::vector` argument types. Avoid relying on flattened, version-sensitive
   wrapper prototypes. Keep module handles opaque; do not guess internal IR
   struct layouts merely to make a probe pass.
3. The new small cloud probe compiles only our source and observes four tiny
   instruction sequences. Synthetic runtime/context offsets are explicitly
   marked. Generated bytes are never executed; unapplied relocations and raw
   disassembly do not prove executable semantics or optimizer correctness.
4. Cache carry requires an explicit clobber contract. Our new scalar pair had
   inherited an unnecessary TBI-mask invalidation from generic fusion handling;
   removing it is justified by the emitted-register contract and a regression
   assertion, not by importing someone else's speedup.
5. Keep correctness-preserving and approximate optimizations separate. No FMA
   contraction, reciprocal substitution or rounding/NaN relaxation is permitted
   for the current six-workload target.

## Local scalar-chain experiment (default OFF)

`vchain` additionally requires a proven `vloop` region and AVX. It recognizes
adjacent same-width MUL -> ADD, retaining separate rounding. Both values remain
in scratch registers until a single hot NaN check; the cold path repairs both
operations in architectural operand order. S/D upper-zero proofs are separate,
reset at public entries, and invalidated by helpers. Public labels/unsupported
aliases are barriers. Exact ON/OFF settings are part of AOT identity; codegen
version is 70. No production binary/default was replaced.

Latest checks: 540,000 directed differential cases (including aliases, NaN
payloads, signed zeros, subnormals, overflow, high XMM registers, tagged pointers
and backedges); real S/D guest and private disk-AOT checks (40 compile/execution
steps); release workspace 170 passed / 1 ignored, core 9 passed. These results
are tied to the measured binary hash in the local evidence, not future edits.

First screen exposed a redundant per-backedge TBI-mask reload. After fixing it,
a **single** same-binary screen measured matmul 53.099 -> 44.932 ms (-15.4%
versus chain OFF), 51.7% of native in that sample. Other workloads varied or
regressed. This is exploratory, not a confirmed 60% result or a promotion to
defaults. Per owner instruction, subsequent iterations use only targeted small
checks and one target screen; full/multi-round acceptance is deferred until a
substantial breakthrough or merge candidate.


## Successful bounded AOT observation (not guest execution)

Run [41099675131](https://github.com/zheznanohana/attesor/actions/runs/41099675131)
on standard ARM64 macOS 26.6.2 (25G83) completed all four own-source cases.
`libRosettaAot.dylib` SHA-256:
`49c3db39b684cd433c19d50cdd9ff6cc924cbb3c912d208e339fc1bcfd51d277`;
reported API version `0x16f0240000000`. The library validated 100 ABI routine
names from the pinned MIT-licensed x87sidecar source. IR text was nonempty and
generated output sizes were 40 / 40 / 32 / 40 bytes (arith / flags / fpchain / loop).

The short arithmetic and FP bodies use register operands without per-operation
CPU-struct traffic. The FP example remains FMUL then FADD, not FMA. The loop
uses SUBS and B.NE. The return-shaped suffix loads guest/shadow values, compares
them and conditionally takes a mismatch path before a host RET. These are
observations of these particular outputs, not recovery of a global allocator,
a validated runtime ABI, or a license to remove Attesor return/epoch checks.
Synthetic context/runtime offsets were used; fixups were not applied; generated
code was never executed. The raw object may also contain stubs/metadata.
Two preceding attempts failed (routine-name validation, then readonly name-table
discovery); they are not counted as successful code-generation observations.

## Subsequent local experiments (codegen 72, all default OFF)

* `funra`: bounded, closed GPR recursive CFG, one private register assignment.
  Execute original guest instructions; no Fibonacci/algorithm substitution.
  LR matching, native-stack bound and epoch checks remain; an activation marker
  prevents unwinding an unrelated parent's frames.
* `funflags`: on CMP-only function CFGs with a spare assigned GPR, retain compact
  NZCV in that GPR and synchronize canonical bytes at observation boundaries.
* `selectra`: one branch for two adjacent same-condition plain CSELs. Both
  paths retain instruction order, aliasing and W zero-extension.
* `vloop2`: a fixed union V assignment across an already-proven private CFG;
  admit audited S/D arithmetic, ordinary S/D memory and GP-to-FP moves. Whole
  128-bit state is loaded/synchronized; never infer join values from emit order.
* `regflags`: extend compact flags to whitelisted CMP-only private loop CFGs.
  Explicitly reject other native flag writers/readers (including FCMP, MSR NZCV,
  ADC/SBC and non-CMP SUBS). MOV EAX,0 before SETO/LAHF avoids a partial-register
  dependency without destroying the live flags needed by the fused branch.

The ten GPR slots and 8/24 V-cache slots already existed. This work changes
lifetimes/contracts, not an inverted Rosetta table or another capacity increase.
All experimental switches are exact tokens, OFF wins, and are part of cache
identity. Full DEFAULT_ON must be retained when explicitly setting JIT_ON.
Production binary/defaults have not been replaced.

## Codegen74: direct scalar outputs and private-CFG flag edge sinking

Two new exact-token, default-OFF experiments. No default/production install change.

`vscalar` requires `vchain`, AVX and an existing audited V-resident region.
It uses VEX/EVEX scalar MUL/DIV/ADD/SUB/SQRT with mapped operands. A destination
that does not alias its inputs is written directly; destructive aliases still
use XMM0 so the original operands survive cold NaN selection. Existing S/D
upper-zero proofs determine when a source can be used directly. The cold repair
contract permits exactly the chosen mapped output in addition to the old scratch
registers; unrelated cached values/GPRs and a live TBI mask remain protected.
No FMA, approximate reciprocal, relaxed NaN policy or widened guest access.

`cfgflags` follows NZCV deadness through bounded private GPR CFGs, including
CB/TB diamonds. Missing/public successors and observers stop the proof. Fused
setter/branch pairs keep host flags live; serialize canonical NZCV only on a
selected public exit when every private successor kills it first. This is not
the earlier compact-LAHF `regflags` experiment: it removes unnecessary work
rather than storing flags in another representation. Reject packed-flag regions,
recursive-function regions, non-native/verification/commpage modes and FP CFGs.
An FPCR guard precedes even a block's first GPR setter, so calling that setter
an incoming-flag kill would be unsound; a directed counterexample covers this.
The observed Rosetta IR live-in/live-out metadata motivates doing explicit local
liveness analysis, not claiming Apple's original algorithm was recovered.

Directed checks (not full acceptance): one scalar test covers 80,000 differential
cases: S/D, all five operations, destructive/non-destructive aliases, low/high
XMM, SSE/AVX512 NaN repair, signed zero/subnormal/infinity/NaN payloads, dirty
upper bits, backedges, plain/patchable exits and FPCR rejection. Two CFG tests
cover 10,512 terminating ADD/SUB/logic, W/X and condition/diamond cases plus
observer/budget/FPCR-entry barriers. No new full-workspace or disk-AOT claim.
The release benchmark binary preceded only the test-case expansion; production
emitter logic is identical. Exact binary hashes are retained with the raw screens.

Performance, same-host unmodified fixtures, no concurrent build/test:

* vscalar: single N-body screen73.5 ->64.5ms (-12.24% time), native21.5ms,
  33.33% native. Useful but still far from60%; not a confirmed multi-round gain.
* cfgflags: sieve initial272.368 ->246.743ms, native153.366ms (62.16%).
  Only this apparent crossing received two extra confirmation rounds, per owner
  request. Across all three, control median272.368ms, candidate median249.418ms,
  native median153.366ms: -8.43% time, 61.49% native by median ratio.
  Individual round ratios were62.16%,52.08%,64.47%. Preserve the slow round:
  median crossing is evidence of progress, NOT a stable60% guarantee or completion
  of the six-workload stage. Cause of the variability is not established.
* A separate one-round configuration hypothesis disabled bgtrans because its
  restricted worker cannot form private loops. Sieve255.068 ->253.466ms (-0.63%):
  no meaningful target gain. Do not disable it by default or claim this explains
  the variation. Incidental qsort/matmul numbers remain in the raw record.

No repeated full configuration matrix. The remaining targets and both qsort
sizes still require one common configuration and final correctness/performance
acceptance. New-contract disk AOT, invalidation/concurrency and full regression
remain pending before production promotion. All experimental flags remain OFF.


## Codegen77: pressure experiments and dependent scalar pairs

All three new switches below are exact-token, default OFF, with OFF precedence.
Production/defaults remain unchanged; cache version is77 plus build UUID/options.

* `xspill` uses otherwise-unused XMM slots for overflow GPR values in proven
  pure-GPR private loop CFGs. Architectural V use (including V memory), calls,
  system/atomic/unproven shapes and recursive-function regions are barriers.
  Assignments are disjoint from native GPR and V assignments. Read W without
  destroying X, preserve SP/XZR distinctions, and synchronize/reload at public
  and helper boundaries. Capacity8 or24 reuses the existing bank, not another
  cache expansion. This first version still bridges scalar operations through
  native GPRs; more capacity does not imply a faster instruction schedule.
* `fmovra` adds a typed GP-to-FP read set for allocation ranking only; the generic
  conservative next-use decoder remains unchanged. Valid W->S/X->D raw transfers
  can go directly between assigned GPR and V registers. XZR is never mistaken
  for an assigned SP; S clears upper V bits without clearing upper source X.
* `vpair` generalizes dependent scalar pairing to MUL/DIV/ADD/SUB/SQRT, including
  overwritten intermediate destinations. Only same-width adjacent instructions
  in an audited fixed-V region are admitted, with no public label/cut between
  them. The second operation must consume the first result, ensuring NaN
  propagation to a single hot guard. Preserve originals until cold repair of
  both architectural NaN selections; commit both live outputs, or just the final
  output if the intermediate is overwritten. Arithmetic remains two separately
  rounded instructions, never FMA/reciprocal/approximation. Retain the existing
  tuned MUL->ADD specialization where it already applies. Unsupported shapes,
  missing V slots and non-propagating operations stay on the old path.

Related checks only, no new full workspace/configuration matrix:

* xspill: three directed tests,512 pressure/diamond/alias/W-X/memory/public-state
  cases, tagged SP and low/high banks; explicit low/high-XMM clobbering helper,
  canonical observer state, all-GPR reload and helper status/early exit; eligibility
  rejects V bank use and unsupported observers.
* fmovra: one test,256 raw-bit/ranking/direct-transfer cases, dirty upper X/V,
  S/D, NaN payloads, signed zero, high XMM, aliases and XZR despite mapped SP.
* vpair: two tests,180,048 interpreter differential cases over all admitted
  operation pairs, aliases, S/D, low/high banks, SSE/AVX512 NaN repair, zeros,
  subnormals, infinities, NaN payloads and backedges; explicit label/type/missing
  input/dependency/non-propagating-shape rejection. Strict cold register/TBI
  contracts remain checked. Existing FPCR entry guards are unchanged.
